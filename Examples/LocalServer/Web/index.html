Pomvox Cleanup Engine local demo

Connecting to the local server…

1. Dictation cleanup

Sends POST /v1/clean, the engine's cleanup wire protocol, to the local server. The reply is the SDK's own CleanupResult: text, edits, outcome, provenance, timings.


  


  

    
2. Speaker notes

    
Record in the browser, or upload a WAV. The page encodes 16 kHz mono PCM and sends it to POST /v1/speaker-notes, where the server runs speech recognition (Parakeet, host side), the on-device diarizer, per-turn cleanup and deterministic notes. Audio goes to 127.0.0.1 only.

What this page is: a client of a local companion process. The browser cannot run the SDK (Swift, Metal, Core ML); the server does, and speaks the same protocols a hosted service would. The bearer token is generated per server start and embedded in this page. Nothing here is a product.
