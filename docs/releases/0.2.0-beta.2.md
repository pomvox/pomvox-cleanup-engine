# Pomvox Cleanup SDK 0.2.0-beta.2

Public **beta** release of the local-first Swift cleanup SDK. It adds the auxiliary-generation entry point for dictionary spelling variants, listing and removal of installed packs, a measured vocabulary-cost table for the reference Mac, and the diarization runtime as its own remote package. The dictation path and default cleanup behaviour are unchanged: prompt, tokenizer, decoding, admission limit, output cap and the pinned `simplewords-v3` pack are the same bytes as 0.2.0-beta.1.

## Install from GitHub

- Core/cloud: `https://github.com/pomvox/pomvox-cleanup-engine.git`, exact version `0.2.0-beta.2`; products `PomvoxCleanup`, `PomvoxNotes`, `PomvoxDiarization` and `PomvoxCleanupCloud`.
- Apple Silicon inference: `https://github.com/pomvox/pomvox-cleanup-mlx.git`, exact version `0.2.0-beta.2`; product `PomvoxCleanupMLX`. It pulls the matching core version automatically. Add it through Xcode so Metal resources are packaged.
- Local diarizer: `https://github.com/pomvox/pomvox-diarization-fluid.git`, exact version `0.2.0-beta.2`; product `PomvoxDiarizationFluid`. Generated from `Runtime/Diarization` by `scripts/export-diarization-release.py` (#25); no local checkout is needed any more.

All three packages are public and MIT licensed (FluidAudio, pulled by the diarizer, is Apache-2.0). Swift 6 is required, with macOS 14+ or iOS 17+. Local inference also requires the separately obtained pinned model snapshot.

## Changes

Auxiliary generation (#3, gap 12): `Cleaner.suggestVariants(for:limit:deadline:)` returns up to `limit` spellings for a term and `[]` on every failure; it never throws and never loads a model. Variants run as a job on the same single worker as `clean`, admitted only when the worker is idle, so they can never take one of the queue slots a dictation needs. Runtimes opt in through the new `AuxiliaryGenerating` protocol; the MLX runtime does not conform yet, and the schema-2 `auxiliaryGeneration` capability (absent or false on schema 1, including `simplewords-v3`) tells a host to hide its chips. The app's variant parser moved in as `VariantParser` with a differential against the app's fixtures. See `docs/packs.md`, "Auxiliary generation: declared unsupported".

Installed packs (#12): `PackInstaller.installed(at:)` lists each pack under a parent directory with its manifest id and version, install date, `allocatedBytes` (what `du` reports; an APFS clone counts in full) and `privateBytes` (what removing it frees). `PackInstaller.remove(_:)` refuses a pack a `Cleaner` in this process holds, renames it aside after a device and inode check, then deletes it. Cross-process holders are not detected, by design; on macOS an open or mapped file survives its directory going away.

Vocabulary cost (#14, gap 6): `docs/packs.md` gains a measured table for `simplewords-v3` on the reference Apple M1 (16 GiB, macOS 15.7.4, Debug), with the raw runs in `docs/evidence/vocabulary-prefill-2026-10-31.json`. With the prefix cache, per-request prefill is flat from 0 to 1,024 terms (148 to 162 ms). The cost that scales is the one-off prefix rebuild on the first request after a dictionary change: 1.6 s at 64 terms, 2.9 s at today's 64 × 32 B worst case, 3.7 s at 256, 7.3 s at 512, 14.1 s at 1,024. That rebuild runs inside the request deadline, so against the 5 s short-text budget a dictionary of 256 or more nine-byte terms falls back to the raw transcript on the first dictation after an edit unless the host warms the cache first. Limits are unchanged in this release; #50 and #51 carry the follow-ups.

Diarization runtime as a package (#25): `scripts/export-diarization-release.py` generates `pomvox/pomvox-diarization-fluid` from `Runtime/Diarization`, and SDK CI gains a `diarization` job that runs the runtime's tests without a model (the real-pack tests skip and say so) and verifies the export.

Tests: `ContractTests.testQueueLimitAndQueueDeadline` (#48) and `VariantTests.testVariantsRunOnTheWorkerAndNeverQueueBehindOrAheadOfACleanup` (#54) no longer depend on scheduling; each had failed once on CI, under the Thread Sanitizer and in the Release configuration respectively.

Compatibility: `Cleaning` gains `suggestVariants` with a default implementation returning `[]`, and `AuxiliaryGenerating` is a new optional protocol, so existing conformers compile unchanged. `PackInstaller` gains two methods; nothing existing changed signature. The cleanup wire protocol is unchanged.

## Read before adopting

This is a beta, not a production-stable release. **iOS is a build target, not a validated platform**: nothing has run on an iPhone here (#30, #2). The diarizer's quality is checked only on synthetic speech (#28). Auxiliary generation is declared but no shipped runtime or pack performs it yet; hosts must treat `[]` as the normal answer.

The model host requires access-condition acceptance. We do not redistribute weights or promise anonymous model downloads. SDK package installation and model acquisition are separate steps. English and bounded vocabulary are supported. Context/style, model-performed auxiliary generation, Intel inference and automatic cloud fallback are unsupported. A still-running canceled worker keeps its resources until it returns.

Real Pomvox microphone/STT integration, sleep/wake and memory-pressure validation, a reviewed quality corpus, a complete supported-platform matrix and an archived model-license record remain stable-production release gates. See `docs/testing.md`.
