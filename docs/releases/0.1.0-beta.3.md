# Pomvox Cleanup SDK 0.1.0-beta.3

Public **beta** release of the local-first Swift cleanup SDK. It adds opt-in host helpers and a capability query; default cleanup behaviour is unchanged.

## Install from GitHub

- Core/cloud: `https://github.com/pomvox/pomvox-cleanup-engine.git`, exact version `0.1.0-beta.3`; products `PomvoxCleanup` and `PomvoxCleanupCloud`.
- Apple Silicon inference: `https://github.com/pomvox/pomvox-cleanup-mlx.git`, exact version `0.1.0-beta.3`; product `PomvoxCleanupMLX`. It pulls the matching core version automatically. Add it through Xcode so Metal resources are packaged.

Both packages are public and MIT licensed. Swift 6 and macOS 14+ are required; local inference also requires Apple Silicon and the separately obtained pinned model snapshot.

## Changes

Capability query: `ValidatedPack.capabilities` and `Cleaner.capabilities` report what an opened pack supports, including the request text admission limit (`maxTextBytes`, 16,384 UTF-8 bytes, unchanged) and the guard set identity (`guardRules`, from `CleanupLogic.rulesVersion`). An optional pack schema 2 declares capabilities; schema 1 packs, including `simplewords-v3`, are unchanged and report the frozen baseline. A schema 2 pack may declare tighter vocabulary limits; `Cleaner.clean` rejects a vocabulary outside them as `incompatible`.

Opt-in host helpers moved from the Pomvox app with their tests: the spoken-layout transform (`CleanupRequest(transforms: [.spokenLayout])`, applied to accepted output only, so fallbacks stay exact input) and `CleanupBudgetPolicy`, a length-sized deadline helper. The default request budget is unchanged.

The output-guard specification is now owned here: every guard vector from the Pomvox app is a table-driven case in `GuardVectorTests` that asserts the rejection reason. Guard behaviour is unchanged.

The MLX runtime source is unchanged from beta.2. Runtime CI builds a remote consumer of the exact pushed commit and verifies resolved package versions.

## Read before adopting

This is a beta, not a production-stable release. The model host requires access-condition acceptance (confirmed at the pinned revision). We do not redistribute weights or promise anonymous model downloads. SDK package installation and model acquisition are separate steps.

English and bounded vocabulary are supported. Context/style, auxiliary generation, unrestricted output length, Intel inference, and automatic cloud fallback are unsupported. A still-running canceled worker retains its resources and lease until it returns. The 1,024-token output ceiling and conservative list guards remain. The admission limit is reported, but requests that cannot fit the output cap are not yet rejected at admission; that check needs the tokenizer (#13).

Actual Pomvox microphone/STT integration, sleep/wake and memory-pressure validation, a reviewed quality corpus, a complete supported-platform matrix, and an archived model-license record remain stable-production release gates. See `docs/pomvox-integration-prompt.md`, `docs/integration-gap-review.md`, and `docs/testing.md` in the tagged core source.
