# Pomvox Cleanup SDK 0.1.0-beta.1

First public, versioned **beta** release of the local-first Swift cleanup SDK.

## Install from GitHub

- Core/cloud: `https://github.com/pomvox/pomvox-cleanup-engine.git`, exact version `0.1.0-beta.1`; products `PomvoxCleanup` and `PomvoxCleanupCloud`.
- Apple Silicon inference: `https://github.com/pomvox/pomvox-cleanup-mlx.git`, exact version `0.1.0-beta.1`; product `PomvoxCleanupMLX`. It pulls the matching core version automatically. Add it through Xcode so Metal resources are packaged.

Both packages are public and MIT licensed. Swift 6 and macOS 14+ are required; local inference also requires Apple Silicon and the separately obtained pinned model snapshot.

## Changes

Vocabulary-prefix reuse; native verified installation with APFS cloning; same-process validated-pack reuse; safe resource retirement; rejection reasons and preserved fallback diagnostics; decoder/cache metrics; configurable global MLX cache clearing; corrected host deadline and stale-insertion handling; and a reviewed app integration prompt.

GitHub CI covers core Debug/Release, both sanitizers, installer/export tests, repeated lifecycle checks, and Xcode consumer builds. The standalone runtime CI resolves the public tagged core dependency. Real-model tests are run locally with network denied and pinned installed artifacts; public CI does not download weights or pretend skipped model tests validate inference.

## Read before adopting

This is a beta, not a production-stable release. The model host requires access-condition acceptance (confirmed at the pinned revision). We do not redistribute weights or promise anonymous model downloads. SDK package installation and model acquisition are separate steps.

English and bounded vocabulary are supported. Context/style, auxiliary generation, unrestricted output length, Intel inference, and automatic cloud fallback are unsupported. A still-running canceled worker retains its resources and lease until it returns. The 1,024-token output ceiling and conservative list guards remain.

Actual Pomvox microphone/STT integration, sleep/wake and memory-pressure validation, a reviewed quality corpus, a complete supported-platform matrix, and an archived model-license record remain stable-production release gates. See `docs/pomvox-integration-prompt.md`, `docs/integration-gap-review.md`, and `docs/testing.md` in the tagged core source.
